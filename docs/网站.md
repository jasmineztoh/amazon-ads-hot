## 构建和发布

1. 先用 Sites 源码助手打开 `site/hosting.json` 登记的现有项目，签出到主仓库同级的 `published-site`。保留此项目的框架依赖、云存储和 MCP 绑定。
2. 复核线索的正文和日期，用已有整理流程生成 `site/collected-content.json`。在 `site/reading-guide.json` 保存逐篇推荐理由、来源角色、事件、阅读路线和关联案例。
3. 在主仓库依次运行 `node scripts/build-preview.mjs` 和 `node scripts/build-site.mjs`。第二步将阅读界面、审核后的内容及 `site/cloud` 的云端功能写入托管源码工作区。
4. 在托管工作区执行 Sites 框架构建，使用源码助手推送与打包同一提交，再部署到原项目。通过原网址检查首页、文章深链、内容接口、热点展示和匿名权限。
5. 将实际部署编号、源码提交和验证结果写入 `site/hosting.json`，与主仓库的内容和代码一起同步 GitHub。采集原文、凭据和本地队列不入库。
