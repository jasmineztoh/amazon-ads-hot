## 更新这个网址

接手的Agent先读取Sites技能与`site/hosting.json`，按项目ID获取现有站点；凭据只在会话中使用，不写文件、命令参数或Git。

1. 整理本地新内容，保持48篇用户标签原件不变。确认新内容的中文摘要和适用条件。
2. 打开现有站点的发布源码工作区到`../published-site`。已存在则复用，不覆盖；缺失时通过Sites现有项目恢复，不能再创建一个站点。
3. 在主仓库执行`node scripts/build-site.mjs`，从当前发布层构建`../published-site/dist`。脚本核对项目登记，并只输出阅读所需字段。先检查页面、搜索、手机宽度和内容数量。
4. 使用Sites提供的发布助手推送源码并从同一提交生成归档，再调用保存版本与部署工具；必须复用原项目、原网址和仅所有者权限。
5. 部署成功后检查线上首页、内容和静态资源，核对匿名请求仍需登录。更新`site/hosting.json`中的版本、部署和验证记录，再将主仓库修改备份到GitHub。

发布失败保留当前线上版本，不删除原站点，不更改权限。需要撤回内容时，先从发布数据移除并重新部署，同时清理对应的已发布旧版本须按托管平台支持的方式处理；仅修改本地文件不会撤回线上内容。
