# 热点

2026-11-17 用户确认：展示近7天最新、最值得关注的3至5条内容。此规则替代此前必须多来源报道、必须精确发布时间的门槛。

- 原文发布日期在近7天且已核实收录即可参与，包含新闻、教程、案例、工具和AI实践。
- 按事件去重后取前5条，不再要求至少两家独立来源。独立来源数只作为排序信号，同机构重复报道不加分。
- 优先使用核实的精确发布时间，缺失时使用已核实的原文发布日期；不使用采集时间冒充发布时间。未来、过期、无日期或撤回内容不参加。
- 综合热度是站内排序指标：AI价值70%＋新鲜度30%（72小时半衰期）＋独立来源覆盖最多10分，上限100。它不是点击量或外部传播数据，也不是经过用户样本校准的效果预测。
- 未评分不伪造分数，显示待评分。AI价值评分原有双评分、模型回执和预算限制保留。
- 少于5个合格事件时显示实际数量，采集任务补充近7天原文，不以旧文凑数。

实现：site/cloud/lib/hot-ranking.ts；行为验证：同目录hot-ranking.test.ts。
