## 启动与日常运行

在仓库根目录运行：

```powershell
node scripts/start-mvp.mjs
```

打开 http://127.0.0.1:4173/ 。启动时检查一次，以后每2小时检查；页面每分钟查看有没有新内容，不会因为有人浏览就调用模型。服务停止、电脑关闭或休眠时，不会继续采集；目前没有开机自启或云端采集。跨设备阅读使用独立网址，本地新内容整理后还需重新发布。按Ctrl+C停止。

只查看已保存的页面，仍可用`node scripts/preview-content.mjs`；页面会明确显示该模式没有开启采集。重新生成页面用`node scripts/build-preview.mjs`，不会把新增内容退回48篇。

需要单独跑一轮更新时：

```powershell
node modules/local-mvp/scripts/run.ts
```

只应用已经整理好的内容、不再联网采集：`node modules/local-mvp/scripts/run.ts --export`。

## 自动化到哪里

自动完成列表读取、原文或RSS全文保存、网址去重、60天采集窗口与未来日期检查、官方现成中文摘要收录、应用已有整理、页面导出和定时检查。

英文内容的中文标题、摘要、要点与推荐特征，本轮由Agent实际阅读材料后整理，记录在`site/editorial.json`，每篇绑定正文哈希。新增英文文章先留队列；尚未接通无人值守的模型翻译、评选与写作。没有模型密钥，没有付费调用；不以关键词规则冒充AI判断。

本轮整理记录22篇：18篇发布、4篇暂不收录，其中发布的3篇是对官方内容补充整理，另外15篇是英文材料。4篇暂不收录是Agent本轮判断，不是用户标出的拒收例，不能拿去伪造用户负例集。官方其余现成摘要另记`publisher-summary`。

本地页面目前77篇、76条：48篇用户原样本，18篇Agent整理，11篇官方摘要。其中14篇是本轮新增官方资料，3篇由Agent补充了测试状态等关键信息。统计是本次交付快照，以页面与`site/collected-content.json`最新内容为准。

## 保存与边界

- `.data/local-mvp/store.json`保存文章状态、来源检查和最近30次运行记录；正文按哈希保存在同目录的`bodies/`。这些研究材料不公开、不提交Git。
- `site/editorial.json`保存Agent决定与正文版本；`site/collected-content.json`和`site/preview/content.json`只保存展示所需的摘要、要点、来源与链接，进入Git版本备份。新检出仓库可先看快照，再恢复采集。
- 使用文件保存，不需要安装数据库服务。并行更新互斥，快照写完后替换；一次来源失败不会删除已有内容。正常退出会释放锁；若电脑强制关闭，接手时核实`run.lock`对应进程已不存在后才移除旧锁，不盲目删除。
- 同一网址的http/https、www、尾斜杠、追踪参数和锚点按原框架规则合并。已审稿正文不会被后续抓取直接改写；原文修订检测仍待后续补充。
- 复用原框架的RSS读取、正文提取、错误页检查、日期精度与网址规范化。官方HTTP通道实测曾只返回1024字节，因此采用已验证的原生读取通道，同时检查固定来源域名、公开地址、每次跳转、超时和大小限制。
- 这是本地MVP模块，没有启用原AI行业worker，没有绕过预算调用付费服务；原框架采集与模型开关仍关闭。未来接正式主站时应接回统一发布层，不长期维护两套生产系统。
